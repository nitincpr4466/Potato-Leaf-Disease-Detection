
# 🥔 Potato Leaf Disease Detection

A CNN-based deep learning application that detects potato leaf diseases using image classification.

## Project Overview

This project uses a Convolutional Neural Network (CNN) built with TensorFlow and Keras to classify potato leaf images into three categories.

## Disease Classes

- Potato Early Blight
- Potato Late Blight
- Potato Healthy

## Technologies Used

- Python
- TensorFlow
- Keras
- NumPy
- Streamlit
- Pillow

## Installation

Clone the repository:

```bash
git clone https://github.com/nitincpr4466/Potato-Leaf-Disease-Detection.git
```

Navigate to the project folder:

```bash
cd Potato-Leaf-Disease-Detection
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
streamlit run app.py
```

## Model Details

- Model Type: Convolutional Neural Network (CNN)
- Framework: TensorFlow / Keras
- Input Image Size: 256 × 256
- Number of Classes: 3
